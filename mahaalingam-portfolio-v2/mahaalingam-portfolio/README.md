# Mahaalingam M — Portfolio

Personal portfolio website for Mahaalingam M, a Computer Science Engineering student at VSB College of Engineering Technical Campus, Coimbatore (Class of 2026).

## 🌐 Live Demo

> Deployed on Vercel

## 🛠️ Tech Stack

- **React 18** + **Vite** — fast build & hot reload
- **Tailwind CSS 3** — utility-first styling
- **Framer Motion** — smooth animations & page transitions
- **Lucide React** — clean icon set

## ✨ Features

- Dark / Light mode toggle (persisted in localStorage)
- Animated loading screen
- Typing effect hero section
- Smooth scroll reveal animations
- Responsive mobile-first design
- Expandable project cards
- Contact form (opens mailto)
- SEO meta tags
